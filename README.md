# OS Multithreading Simulator

A Python-based simulation of parallel order processing
using multithreading for the Operating Systems course.

## Project Overview

This project simulates the processing of 100 online
store orders using multiple threads.

- Total orders: 100
- Processing time per order: 1 second
- Distribution: Static Distribution
- Synchronization: Thread.join()

## Technologies

- Python
- threading
- time
